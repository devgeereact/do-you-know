## ADR-023 detail: open owner calls, 8 Nov 2026

Status words: DECIDED = adopted default; PLANNED = not built; OWNER = needs your own action (Studio, server, GitHub).

1. **Ranked and daily time cap.** DECIDED: cap each question at 30 seconds in ranked and daily rounds only; practice, learning sessions and children stay untimed. The server checks the time (never the browser). PLANNED, no migration expected.
2. **Daily by level.** DECIDED: keep today's all-bank hands until parents have set levels for a while; then per-level hands and crowns. PLANNED.
3. **18+ age gate.** DECIDED: a quiz with no minimum age counts as suitable for everyone; adult sets must carry `age_min` 18 and the server already keeps them from guests and children. PLANNED: a Studio publish warning when an adult-looking set has no `age_min`.
4. **Christian baptism and Last Supper questions.** DECIDED: do not publish. They are sacraments, which the Christian-only rule keeps out (`docs/AUDIT.md`, 8 Nov). Kept as unpublished drafts, nothing deleted.
5. **Odd age bands on existing quizzes.** DECIDED: move to the standard bands. OWNER: a Studio edit (list in `docs/LEARNING-DESIGN.md` section 8); no code.
6. **Landing page direction.** DECIDED: keep the new honest home (real counts, four areas, no adult sets up front) as the base; visual polish only after it has been checked on a phone. PLANNED.
7. **Dependabot.** DECIDED: #11 (eslint-plugin-react-refresh 0.4 to 0.5) close and ignore until the lint stack is upgraded; #10 (actions group) is checkout 4 to 7 and pnpm/action-setup 4 to 6 inside `deploy.yml`, so it is a planned task too and stays open (revised 8 Nov after reading it); #8 (clerkinc/backend-php 1 to 2) is a major upgrade, so a planned task, close for now. #11 and #8 were closed on GitHub on 8 Nov 2026 after the release approval.
8. **The 61 drafts** (38 P3 + 23 P6). DECIDED: import P3 first, then P6, one file at a time, read the notes, publish only what you have read, set difficulty, then one release to prerender. OWNER: Studio.
9. **`mail_from`.** DECIDED: a no-reply address on the site's own domain, with SPF and DKIM set first so replies are not marked as spam. OWNER: private server config and DNS; until then replies are saved and marked "not emailed".
