# Regression Tests

Add a focused test for every material defect whose recurrence can be detected automatically. Link it to the issue or decision.

Put the test where the defect lives: a rule or hook in `tests/unit`, a player journey in `tests/e2e`, a server rule in `backend/tests`. Name the test after the symptom and note the issue, pull request or decision in a comment above it. This folder is for regression checks that fit none of those.
